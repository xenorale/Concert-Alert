# 🎸 Concert Radar · Воронеж

Телеграм‑бот, который следит за концертами выбранных тобой артистов в Воронеже.
Раз в сутки (12:00 МСК) он проверяет [Афишу](https://www.afisha.ru/voronezh/schedule_concert/)
и присылает уведомление с афишей, датой, площадкой и ссылкой на билеты, если кто‑то из
твоих артистов едет в город. Артистов можно добавлять и удалять прямо из чата.

Всё работает на бесплатных GitHub Actions — отдельный сервер не нужен.

---

## Как это устроено

| Часть | Источник |
|-------|----------|
| Концерты | `afisha.ru` — разбор `schedule_concert` (JSON‑LD `MusicEvent`) |
| Фото и имена артистов | Deezer API (без ключей) |
| Уведомления и команды | Telegram Bot API |
| Расписание | GitHub Actions (cron) |
| Состояние | JSON‑файлы в `data/`, бот сам коммитит изменения обратно |

Два рабочих процесса:

- **`daily-check.yml`** — каждый день в 09:00 UTC (12:00 МСК) проверяет афишу и шлёт уведомления.
- **`bot.yml`** — каждые 5 минут забирает команды из Telegram (`/add`, `/remove`, `/list`, `/search`, `/check`).

---

## Настройка

1. **Создай репозиторий** (или используй этот) и запушь код.
2. **Сделай репозиторий публичным** — тогда минуты GitHub Actions бесплатны и не ограничены.
   В приватном репозитории бот тоже работает, но тратит лимит в 2000 минут/мес.
3. **Добавь токен бота как секрет:**
   `Settings → Secrets and variables → Actions → New repository secret`
   - Имя: `TELEGRAM_BOT_TOKEN`
   - Значение: токен от [@BotFather](https://t.me/BotFather)
4. **Включи Actions:** вкладка `Actions → I understand my workflows, enable them`.
5. **Напиши боту `/start`** в Telegram — так он узнает твой чат и начнёт присылать уведомления.
6. **Добавляй артистов:** пришли имя артиста сообщением или командой `/add Скриптонит`.

> Первая проверка произойдёт по расписанию. Чтобы запустить вручную сразу —
> `Actions → Daily concert check → Run workflow` или напиши боту `/check`.

---

## Команды бота

| Команда | Действие |
|---------|----------|
| `Имя артиста` (просто текст) | добавить артиста |
| `/add <артист>` | добавить артиста |
| `/remove <артист>` | удалить артиста |
| `/list` | показать всех артистов |
| `/search <артист>` | найти артиста (с фото), не добавляя |
| `/check` | проверить афишу прямо сейчас |
| `/help` | справка |

## Локальный запуск

```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN=...      # PowerShell: $env:TELEGRAM_BOT_TOKEN="..."

python main.py add "Three Days Grace"
python main.py list
python main.py check               # разовая проверка и рассылка подписчикам
python main.py bot                 # разовая обработка команд
```

## Заметки

- **Город** задаётся в [radar/config.py](radar/config.py) (`AFISHA_SCHEDULE_PATH`, `CITY_NAME`).
  Под другой город достаточно поменять slug в пути Афиши.
- **Безопасность:** токен хранится только в секретах репозитория, в коде его нет.
  Если токен где‑то засветился — перевыпусти его в @BotFather и обнови секрет.
- GitHub отключает запланированные workflow после 60 дней полного бездействия в репозитории —
  обычная переписка с ботом и ежедневные коммиты состояния этого не допускают.
